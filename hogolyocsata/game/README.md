# Mazsola Klub – Hógolyócsata v1.8

## Módosítások
- A felhasználó által feltöltött `logo(1).png` használata a főmenüben, faviconként és PWA-ikonként, 192/512 px kimenetekkel.
- Főmenü emblémája több mint kétszeres méretben, a rendelkezésre álló felső teret kitöltve.
- A két főmenü-karakter mérete 10%-kal nőtt (22%-ról 24,2%-ra).
- A közösségi linkek akadálymentes, kattintható és ikon-only gombok; elegendő térközzel a „Rólunk” alatt.
- Megmaradt a játék teljes v1.7-es funkciókészlete, a grafika, a zene, a hanghatások és a téli dalok linkje.

Kicsomagolás után az `index.html` fájllal indítható böngészőben. A zene böngészőkorlátozás miatt az első interakciótól indulhat.

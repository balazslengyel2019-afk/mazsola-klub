Mazsola Klub Halloween WEB v2.0
================================

A csomag teljesen statikus: nincs szükség adatbázisra vagy backend-re.

TELEPÍTÉS
1. Töltsd fel a ZIP tartalmát a webszerver egy mappájába, például /halloween/ vagy /game/.
2. Az index.html legyen a mappa gyökerében.
3. HTTPS használata javasolt, különösen mobilon és PWA módban.

FŐ FUNKCIÓK
- 3 másodperces, néma Mazsola Klub intro, áttűnéssel
- 8 karakteres 4x2 karakterválasztó
- vámpír, csontváz, szellem, múmia, varázsló, boszorkány, tökjelmez, farkas
- endless runner játékmenet
- double jump
- random édességek több magasságban
- random békák
- boszorkányos game over animáció
- rekord mentése localStorage-ba
- zene ki/be a főmenüben, karakterválasztóban és játék közben
- egér/touch + Space/nyíl-fel vezérlés
- reszponzív, fekvő 16:9-es megjelenés

VERZIÓ: 2.0 WEB
